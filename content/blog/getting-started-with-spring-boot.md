Spring Boot is what convinced me that Java could be as productive as the JavaScript frameworks I had been working in. Dependency injection and auto-configuration meant I could focus on application logic instead of wiring everything together by hand.

## What I Learned

- **Java Fundamentals** — types, classes, interfaces, and generics as the foundation the framework builds on
- **Dependency Injection** — letting the container construct and supply collaborators instead of wiring them manually
- **Auto-Configuration** — how Spring Boot reduces boilerplate setup by configuring sensible defaults automatically
- **REST Controllers** — mapping endpoints with annotations, handling request bodies, and returning JSON responses
- **Project Structure** — organizing a backend into layers that stay maintainable as the application grows

## Building Real Projects

Applying these ideas to backend services with Java and Spring Boot meant structuring a real application rather than a demo — exposing REST APIs, handling data between layers, and connecting that backend to a frontend interface.

## Where I Am Now

Java and Spring Boot are my current focus for backend work. I understand how the framework assembles an application, which means I can build REST services, track down failures, and make architectural decisions with confidence.
